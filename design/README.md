# Context — лендинг: материалы для разработки

Задача: сверстать одностраничный статичный лендинг продукта **Context** (личная CRM для знакомств) по готовому макету. Стек: **Astro 5 + Tailwind CSS 4**, без клиентского JS. Одна страница, одно целевое действие — перейти в приложение (кнопка «Начать бесплатно»).

## Что в папке

| Путь | Что это |
|---|---|
| `README.md` | Этот бриф: стек, структура, спецификация блоков, критерии приёмки |
| `PROMPT.md` | Готовый стартовый промпт для Claude Code |
| `content.md` | Все тексты — источник истины для копирайта |
| `tokens/global.css` | Токены Tailwind 4 (`@theme`): цвета, шрифты, пиксельные тени, фон-сетка |
| `reference/mobile.html` | Эталон мобильной версии (390 px), открывается в браузере |
| `reference/desktop.html` | Эталон десктопа (1440 px), открывается в браузере |
| `screenshots/*.png` | Скриншоты эталонов @2x: целиком и первый экран |
| `assets/icons/*.svg` | Пиксельные иконки (`currentColor`, кроме `cursor.svg`) |
| `assets/fonts/` | woff2 (кириллица + латиница) и `fonts.css` — запасной вариант, если не ставить @fontsource |

Эталонные HTML — это экспорт из дизайн-инструмента: инлайн-стили, абсолютные px. **Не копировать их разметку как есть**, а пересобрать на Tailwind-классах и компонентах. Значения (размеры, отступы, цвета) брать из них и из таблиц ниже.

## Стек и настройка

```bash
npm create astro@latest context-landing -- --template minimal --typescript strict
cd context-landing
npx astro add tailwind          # Tailwind 4 через @tailwindcss/vite
npm i @fontsource/rubik-mono-one @fontsource/press-start-2p @fontsource/golos-text
```

- `src/styles/global.css` ← содержимое `tokens/global.css` (там уже есть `@import "tailwindcss"` и импорты шрифтов).
- Иконки положить в `src/icons/` и вставлять инлайном (через `?raw` или Astro-компонент `PixelIcon.astro`), чтобы работал `currentColor`.
- Ссылка CTA — из переменной окружения `PUBLIC_APP_URL` (`.env.example`: `PUBLIC_APP_URL=https://app.example.com`). Все три кнопки ведут на неё.
- `output: 'static'`, без интеграций кроме Tailwind. Никаких React/Vue-островов.

## Структура

```
src/
  layouts/Base.astro            # <html lang="ru">, meta, global.css
  pages/index.astro             # собирает секции по порядку
  components/

    PixelButton.astro           # тёмная кнопка с фаской + пиксельная стрелка
    PixelIcon.astro             # инлайн-SVG по имени

    sections/FinalCta.astro

```

## Визуальная система

- Фон всей страницы — лавандовая сетка (`bg-grid`), блок «Выгоды» — тёмная сетка (`bg-grid-night`) во всю ширину.
- **Никаких скруглений.** Рамки 2px `ink`, жёсткие тени без размытия (`shadow-px*`).
- «Окно»: title bar высотой 34px (моб) / 40px (деск), снизу граница 2px; слева название моноширинным пиксельным шрифтом 9/11px, справа 2–3 квадратика 14/16px (белые с рамкой, последний залит `ink`). Тело белое.
- Кнопка CTA: фон `ink`, белый текст `font-pixel`, `shadow-bevel`, справа иконка `arrow-right` цвета `accent`. Высота 56 (hero моб) / 60 (финал моб) / 64 (hero деск) / 68 (финал деск). Hover: фон `#000`, фаска остаётся; focus-visible: outline 3px `violet`, offset 3px.
- Заголовки — `font-display`, `uppercase`, вес 400. Выделенное слово — `text-violet` на светлом, `text-accent` на тёмном.
- Пиксельные SVG всегда с `shape-rendering: crispEdges`, размеры кратны сетке иконки.
- Декоративные элементы (звёздочки, сердечки, курсор, повёрнутые окна) — `aria-hidden="true"`, `pointer-events-none`.

## Адаптив

- Mobile-first. Эталон мобильной версии — 390 px, контент с боковыми отступами 16px.
- С `lg` (1024px) включаются десктопные раскладки. Контейнер `max-w-[1280px] mx-auto px-10`.
- Между 768 и 1024 допустим мобильный порядок с увеличенной типографикой, главное — без горизонтального скролла.
- Проверить 360, 390, 768, 1024, 1280, 1440, 1920.

## Блоки (сверху вниз)

### Шапка
- Моб: только логотип `Context`, высота 44.
- Деск: логотип слева; справа маленькая кнопка «Начать бесплатно» (белая, рамка 2px, `shadow-px-sm`, h 44, pixel 10px). Это та же ссылка на приложение.

### 1. Hero
- Моб: окно `контакты.exe` (title bar accent, 3 контрола, `shadow-px-md`; паддинги тела 22/18, gap 18): H1 → лид → кнопка во всю ширину. Ниже область 250px с повёрнутым на −2° окном `напоминание` (title bar lilac, иконка `bell`), пиксельный курсор слева снизу, `sparkle` accent справа сверху, `heart` accent справа снизу.
- Деск: две колонки (`flex-wrap`, gap 56): слева окно `контакты.exe` (`shadow-px-lg`, паддинги 44, gap 28, кнопка по ширине текста); справа композиция высотой 520: окно `карточка` (title bar butter, повёрнуто +3°) и под ним окно `напоминание` (−2°), плюс курсор, звёздочки, сердце. Отступ сверху от шапки 56, снизу 96.

### 2. Проблема — «Знакомо?»
- 4 белые карточки (рамка 2px, `shadow-px`): слева квадрат 26/34px accent с «!» пиксельным шрифтом, справа текст.
- Моб — столбик, gap 12. Деск — сетка 2×2, gap 20, паддинги карточки 24.
- Под ними тёмная плашка `ink` с `shadow-bevel` и иконкой `heart-broken` (accent): «Полезные связи…», моб 16px semibold, деск 22px.
- В 4-й карточке «Саша (митап)» — инлайн-плашка `font-pixel` на `butter`.

### 3. Решение — «Ваша личная база знакомств»
- Моб: заголовок + лид, ниже окно `возможности` (title bar lilac, справа «5 объектов»), 5 строк, разделители 2px dashed lilac.
- Деск: две колонки — слева заголовок, лид и `sparkle` (flex 1), справа окно (flex 1.5).
- Строка: иконка-квадрат 40/48px (фон paper, рамка 2px) + h3 + текст. Иконки: `sparkle`, `check`, `clock`, `search`, `lock` (у «Только ваше» квадрат залит `ink`, иконка accent).
- «Теги и поиск»: теги `врач` (accent), `инвестор` (lilac), `Москва` (butter), `конференция 2026` (white), рамка 1.5px.

### 4. Выгоды — «Что изменится» (тёмная полоса во всю ширину)
- Карточки: фон `night-card`, рамка 2px `lilac`, квадрат-чекбокс accent с иконкой `check` (ink).
- Моб: столбик, gap 12, чекбокс слева от текста.
- Деск: сетка из 3 колонок, 5 карточек + 6-я декоративная ячейка (рамка dashed `night-dash`, сердце по центру, `aria-hidden`). Чекбокс над текстом.
- Карточка 3 содержит «переписку»: зачёркнутый пузырь слева (`night-chip`, текст `night-muted`) и выделенный справа (фон accent, текст ink, рамка 2px white).

### 5. Финальный призыв
- Окно `новое_знакомство.exe` (title bar accent, 2 контрола). Моб: на всю ширину, текст слева. Деск: по центру, max-w 900, текст и кнопка по центру, паддинги 56.
- H2 → текст → кнопка «Начать бесплатно».
- Вокруг 1–2 декоративные звёздочки.

### Футер
- `Context` (pixel 10/12) слева, `heart` accent справа. На десктопе сверху линия 2px ink.

## Доступность и качество

- Семантика: `<header>`, `<main>` с `<section aria-labelledby>`, один `<h1>`, далее `<h2>`/`<h3>`.
- Кнопки — `<a href={PUBLIC_APP_URL}>`, у всех видимый текст; тап-зона ≥ 44px.
- Контраст текста ≥ 4.5:1 — проверить пары из токенов (особенно `ink-faint` на `paper` и `night-muted` на `night-chip`); при недоборе затемнить/осветлить токен, а не отдельный элемент.
- `prefers-reduced-motion`: анимаций в макете нет; если добавлять hover-сдвиги — отключать.
- Шрифты self-hosted (@fontsource), `font-display: swap`, preload `Rubik Mono One` cyrillic.
- Мета: `title`, `description`, Open Graph, `lang="ru"`, favicon — пиксельное сердце из `heart.svg` (accent).
- Lighthouse: Performance, Accessibility, Best Practices, SEO ≥ 95 на мобильном.

## Критерии приёмки

1. На 390 px страница визуально совпадает с `screenshots/mobile-full.png`, на 1440 — с `desktop-full.png` (допуск по отступам ±4px, переносы строк могут отличаться).
2. Все тексты совпадают с `content.md` дословно.
3. Нет горизонтального скролла на 360–1920.
4. В сборке `dist/` нет клиентского JS.
5. Все CTA ведут на `PUBLIC_APP_URL`.

## Известные отличия эталона от финала

- Эталонная мобильная версия имеет искусственную `min-height: 4300px` (пустота внизу скриншота) — в вёрстке её не должно быть, высота по контенту.
- В эталонах `href="#start"` — заглушка.
